# Мои финансы — PWA 1.0

Мобильное приложение для Android в тёмной теме. Данные хранятся только в IndexedDB браузера на устройстве. Нет регистрации, облачной базы, трекеров, внешних библиотек или связи с банком.

## Что работает

- Главная: общий баланс, 4 виртуальных счёта, доходы и расходы за текущий месяц, быстрые действия.
- Доходы: произвольная категория, автоматическое распределение по редактируемым процентам либо один выбранный счёт; точные расчёты в центах.
- Расходы: категория и счёт выбираются вручную. Операции могут увести баланс счёта в минус.
- Переводы между счетами, корректировка баланса (точное значение, добавление, вычитание).
- История: поиск, фильтр, детали, редактирование и удаление операций, ручная дата.
- Категории доходов и расходов: создание, переименование, иконки, архивирование, удаление неиспользуемых.
- Бюджеты по категориям: каждый месяц или разовый на определённый месяц; разовый перекрывает регулярный. Превышение не блокирует расход.
- Курьерство: временная оплата компании из «Обязательных расходов», отслеживание задолженности, частичный возврат наличными, подтверждённые чаевые как доход; собственные внесённые наличные не добавляются в доход.
- Подписки: вручную задаваемые платежи и даты, список ожидаемых, запись расхода кнопкой «Оплачено». **Никакого автосписания**.
- Аналитика: суммы по месяцам, расходы по категориям.
- Копии: полная выгрузка JSON, восстановление с проверкой структуры и подтверждением замены, выгрузка операций CSV для Excel.
- Напоминания о резервных копиях и подписках **внутри интерфейса**, когда приложение открывается.

## Как открыть и установить на Android

1. Распакуй архив. В корне папки находятся `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest` и папка `icons`.
2. Опубликуй эти статические файлы через любой HTTPS-хостинг для статических сайтов (например, Netlify Drop или GitHub Pages). **Серверная база данных не нужна** — хостинг раздаёт лишь файлы интерфейса.
3. Открой полученную HTTPS-ссылку на Android в Google Chrome.
4. В меню Chrome выбери «Установить приложение» или «Добавить на главный экран» (название может отличаться).
5. После первой полной загрузки приложение сможет открываться без интернета благодаря service worker.

Важно: открытие файла `index.html` прямо из архива / файлового менеджера **не является корректной установкой PWA**. Для service worker и полноценной установки требуется HTTPS либо localhost для локальной разработки.

### Локальная проверка на компьютере

В папке приложения запусти `python -m http.server 8000` и открой `http://localhost:8000`. Работает только в поддерживаемом браузере с включённым IndexedDB. Тестовую и основную копию приложения лучше держать отдельно, так как данные привязаны к адресу сайта и браузеру.

## Резервные копии и конфиденциальность

«Ещё → Резервные копии → Создать резервную копию» сохраняет JSON-файл через загрузки браузера. Перенеси его в безопасное хранилище **вне телефона** (например, личный Google Drive); локальная копия не защитит от потери устройства. JSON не зашифрован — любой, кто получит файл, сможет прочитать финансовые данные.

«Восстановить из JSON» **полностью заменяет** текущее состояние после подтверждения. Сначала сохрани резервную копию текущих данных.

**Не очищай данные сайта и не переустанавливай приложение, не сохранив отдельную резервную копию**. Переход на другой домен или браузер не переносит IndexedDB — используй экспорт/импорт JSON.

## Ограничения текущей 1.0

- Не проводились испытания на конкретном телефоне пользователя. Это рабочий первый выпуск, а не окончательно отлаженное банковское ПО.
- Нет автоматической синхронизации между устройствами, серверных резервных копий или фоновых push-уведомлений. Напоминания видны при открытии приложения.
- Нет импорта записей из прежней Excel-таблицы и автоматического получения операций из банков или Bolt/Wolt.
- Отдельные курьерские записи при исправлении суммы проще удалить и записать заново. Удаление курьерской оплаты блокируется, если из-за него учтённые возвраты превысят общую сумму оплат.
- Балансы четырёх счетов виртуальные; их нужно вести вручную. Названия счетов и проценты настраиваются; число счетов в этой версии фиксировано — четыре.
- У приложения нет встроенного пароля/шифрования данных на устройстве. Используй блокировку Android и осторожно храни резервные копии.

## Файлы

`index.html` — каркас; `styles.css` — тёмный адаптивный интерфейс; `app.js` — экранная логика, расчёты, IndexedDB, экспорт/импорт; `manifest.webmanifest` — параметры PWA; `sw.js` — кеш для офлайн-запуска; `icons` — иконки приложения.
